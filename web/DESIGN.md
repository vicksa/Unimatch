# UniMatch visual identity

The generated U/heart symbol lives in `public/unimatch-logo.png`. Use the shared `Brand` component for wordmarks. Do not use stock portraits for sample profiles. Public visitors start on the welcome page; demonstrations are explicitly labeled and opened by the visitor.

| Role | Color |
| --- | --- |
| Primary action / selected navigation | `#6D4AFF` |
| Accent surface | `#F0ECFF` |
| Page background | `#F8F7FC` |
| Card / field surface | `#FFFFFF` |
| Main text | `#292438` |
| Secondary text | `#706A7E` |
| Border | `#E8E5EE` |
| Decorative accent | `#FF8D83` |

Tokens are defined in `production-design.css` and shared with Clerk appearance and the web manifest. Coral is decorative; destructive actions retain red. Use system sans-serif fonts without external font requests. Prefer 8/12/16/24/32 px spacing, 12–16 px control radii and 20–24 px card radii. Main touch targets are at least 44 px. Honor `prefers-reduced-motion`. Profile photos remain private authenticated images; the brand symbol uses Next Image optimization.

The APK's embedded screens receive this web design automatically when online. Its installed launcher icon belongs to the separately built Android binary.
